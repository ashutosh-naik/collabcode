# CollabCode

A real-time collaborative code editor — multiple developers can join the same
workspace, edit code simultaneously, chat, and execute code securely.

## Status

🚧 Under active development. Follow along with the commit history to see how
this project was built from scratch.

## Planned Features

- Authentication (email/password, OAuth)
- Real-time collaborative editing (CRDT-based)
- Presence & live cursors
- In-workspace chat
- Secure sandboxed code execution
- Version history

## Tech Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS, Monaco Editor
- Backend: Node.js, TypeScript, PostgreSQL, Redis
- Real-time: WebSockets + Yjs (CRDT)

More details will be added as each part is built.
